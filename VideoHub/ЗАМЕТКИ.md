# Студия Монетизации: заметки по нашему чату

Этот файл — «память» о разговоре, чтобы продолжить работу с ПК или в новой сессии.
Здесь записано, что просили, что сделано и какие решения приняты.

## Что просили (кратко, своими словами)

- Программа для **Windows**, полностью отдельная от Claude.
- Выкладывать видео на **несколько каналов и платформ**: YouTube и TikTok.
- Два канала с историями (видео делает Claude): **RU и EN**. Озвучки разные, поэтому это **два разных видео**.
  Для каждого видео отдельно: файл, название, описание.
- Кнопка **«Выложить»** или выбор **времени**, чтобы видео вышло само, без участия человека и без включённого ПК.
- Отдельно — **нарезки ютуберов и стримеров**, их выкладывать на **несколько TikTok-аккаунтов**. Всего будет около 5–6 аккаунтов.
- **Статистика**: общая и по каждому видео — когда зрители уходят, когда свайпают и т.д.
- **Анализ**: найти видео, которые за выбранный период набрали меньше всего просмотров, и написать, что улучшить.
- Интерфейс в **зелёно-фиолетовых** цветах, понятный и приятный для глаз.
  Вкладки: «Анализ», «Видео», «Выложенные», «Статистика».
- Потом добавили:
  - название **«Студия Монетизации»**;
  - уведомления — в **Telegram** (видео вышло, первые 10К просмотров и т.д.);
  - **Telegram-бот**;
  - календарь и уведомления Windows **не нужны**;
  - описание вкладок и идеи, что ещё добавить.
- На будущее: возможно, **объединить с Discord-ботом очков** (`index.js` в корне этого репозитория).

## Принятые решения

| Вопрос | Решение |
|---|---|
| Платформы | YouTube и TikTok (Instagram — нет) |
| Расписание TikTok | TikTok не умеет публиковать по времени через API → программа выкладывает сама. Для этого ПК должен быть включён (достаточно трея). Свой сервер не делали. |
| Расписание YouTube | Видео загружается сразу как скрытое с датой публикации, YouTube открывает его сам — ПК можно выключить |
| ИИ | Бесплатно: встроенный анализ по правилам + Google Gemini (бесплатный ключ). Claude API — необязательно. Без ключей — «Скопировать для Claude» → вставить ответ обратно |
| Технология | Electron (Node.js) + обычные HTML/CSS/JS, без сборщиков. Установщик — NSIS |

## Ограничения платформ (честно)

- **TikTok без одобрения приложения** публикует только **приватно**. Обходной путь — режим «В черновики TikTok».
- **TikTok API не отдаёт** удержание и свайпы — только просмотры, лайки, комментарии, репосты.
- **YouTube API отдаёт** кривую удержания, но **не отдаёт** «просмотрено / пролистано» для Shorts — это есть только в YouTube Studio.
- **Квота YouTube API**: около 6 загрузок в сутки на один проект Google Cloud. Можно запросить увеличение или сделать второй проект.
- **ИИ YouTube Studio** нельзя вызвать из программы, поэтому анализ делает Claude.

## Вкладки программы

1. **Видео** — черновики. Добавить файл (кнопкой или перетаскиванием), вписать название, описание и хэштеги, выбрать тип (Истории или Нарезки) и язык (RU или EN).
   - Подходящие аккаунты отмечаются сами, шаблон описания подставляется сам.
   - Кнопка «копия» создаёт версию на другом языке, связанную в пару.
   - «Помощь ИИ» — варианты названий, описание, хэштеги и идея хука.
   - Здесь же «Выложить» и «На время» (с подсказкой лучшего времени).
2. **Выложенные** — загружаются, с ошибками (кнопка «Повторить»), запланированы, выложены. Прогресс по каждому аккаунту, ссылки на видео.
3. **Статистика** — три режима:
   - **По видео**: просмотры, лайки, досмотр, подписки; график удержания (где уходят зрители); сколько осталось на 3-й секунде; откуда пришли зрители; рост просмотров.
   - **Лучшее время**: тепловая карта «день недели × время», во сколько раз видео набирают больше обычного.
   - **RU ↔ EN**: сравнение языковых версий одной истории.
4. **Анализ** — Claude разбирает статистику за период. Находит самые слабые видео (относительно обычных для аккаунта) и объясняет причины. Даёт план на следующие видео. Можно задать свой вопрос. Есть история анализов.
5. **Монетизация** — прогресс до условий:
   - **YouTube**: 1000 подписчиков + 10 млн просмотров Shorts за 90 дней или 4000 часов; начальный уровень тоже показан. Есть прогноз, когда дойдёшь.
   - **TikTok Creator Rewards**: 10К подписчиков + 100К просмотров за 30 дней. Отдельно подсчитаны видео от 1 минуты — деньги платят только за них.
6. **Telegram** — свой бот:
   - **Уведомления**: видео вышло или запланировано, рубежи просмотров (1К, 10К, 50К…), рубежи подписчиков, ошибки с кнопкой «Повторить», итоги дня.
   - **Команды**: `/stats`, `/top`, `/weak`, `/queue`, `/drafts` (выложить черновик с телефона), `/money`, `/refresh`, `/analyze`.
7. **Нарезка моментов** — встроенный ClipApp: вкладка запускает установленный ClipApp (обычно `E:\ClipApp`) в режиме `--server-only` и показывает его интерфейс. Готовые экспорты (папка с `clips.json`) одной кнопкой уходят в черновики «Видео» с названиями и хэштегами, на аккаунты с типом «Нарезки». Исходники ClipApp — в папке `ClipApp/` репозитория.
8. **Помощник** — чат на Google Gemini (бесплатный ключ с aistudio.google.com/apikey). Видит каналы, статистику, черновики и последний анализ. Тот же Gemini делает «Анализ» и «Помощь ИИ» в редакторе; в Telegram — команда `/ask`.
9. **Настройки** — аккаунты (язык, тип, шаблон по умолчанию), ключи доступа, шаблоны, автозапуск, трей, частота обновления статистики, инструкции по подключению.

## Что можно добавить дальше (идеи)

- **A/B-тест названий**: через сутки сменить название на YouTube, если видео не набирает.
- **Нарезка**: из длинного видео стримера по таймкодам сделать несколько клипов (через ffmpeg) и сразу поставить их в очередь.
- **Автосубтитры** и проверка длины ≥ 61 с для TikTok Creator Rewards перед загрузкой.
- **Учёт доходов**: ввод заработка по каналам, график RPM.
- **Свой сервер** (≈5 $/мес) — чтобы TikTok по расписанию работал без включённого ПК.
- **Объединение с Discord-ботом** — например, раздавать очки участникам за репосты или делать анонсы новых видео в Discord.

## Где что лежит

- `VideoHub/` — код программы (папка осталась со старым названием).
  - `main.js` — главный процесс;
  - `src/` — YouTube, TikTok, Telegram, ИИ, хранилище;
  - `renderer/` — интерфейс;
  - `build/` — установщик.
- Данные программы на ПК: `%APPDATA%\MonetizationStudio\studio-data.json`. Ключи и токены там зашифрованы средствами Windows.
- Сборка установщика (Linux, нужны `nsis`): `cd VideoHub && npm install && npm run dist` → `dist/MonetizationStudio-Setup-<версия>.exe`.

## Как продолжить

- Эта сессия видна с ПК: claude.ai/code (или приложение Claude) под тем же аккаунтом.
- В новой сессии можно сказать: «прочитай VideoHub/ЗАМЕТКИ.md и продолжим».
  Это сработает, если код сохранён на GitHub. Для этого нужен доступ Claude к репозиторию: claude.ai/connect-github.
